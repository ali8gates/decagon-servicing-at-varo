# Plain language glossary

| Term | Meaning |
|---|---|
| Decagon | The support assistant Varo uses in its in-app chat |
| Amazon Lex | The old scripted chatbot |
| Support assistant | Software that understands a request in normal language and can answer or take an action |
| Workflow (AOP) | Step by step instructions the agent follows for a task, written mostly in plain English |
| Resolved without a person (deflection) | The chat ended with the customer helped and no human needed |
| Success rate | Share of chats the bot handled successfully |
| Handoff (escalation) | Passing the chat to a human agent |
| Net promoter score | Promoters minus detractors, from minus 100 to plus 100 |
| Satisfaction score (CSAT) | Post-chat rating of the experience |
| Watchtower | An automatic monitor that scans every chat for a specific risk |
| Answer checker | A second automated step that reviews each answer before it is sent |
| Standard test questions | Fixed questions rerun before every change |
| Data lake | Varo's central store of data for reporting |
| Gradual rollout | Moving a small share of customers first, then more |
